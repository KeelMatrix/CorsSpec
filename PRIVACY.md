# Privacy

KeelMatrix.CorsSpec does not collect or transmit telemetry and performs no independent or background network activity. It does not contact the origin named in a scenario or resolve a hostname. It intentionally sends the scenario path, `Origin`, and preflight metadata through the `HttpClient` supplied by the caller, then evaluates returned CORS headers locally.

The caller controls any network behavior of that `HttpClient`, including routing and any caller-added headers. The scenario API accepts caller-added header names without their values; list those names when they are supplied through default or per-request handler configuration so CorsSpec can conservatively send the preflight a browser may require. Browser-managed, forbidden, and conditional override header names are rejected before the caller's handler is invoked. CorsSpec does not add cookies, bearer tokens, or authorization values, and it does not copy response bodies, credentials, or diagnostics to a CorsSpec service. Use a test host or another intentionally configured handler for offline validation.
